# Contributing

Thanks for your interest in contributing!

## How to Contribute

1. Fork this repository
2. Create a feature branch (`git checkout -b my-feature`)
3. Make your changes
4. Run tests if applicable (`bats script_dir/test/*.bats`)
5. Commit with a clear message
6. Push to your fork and open a Pull Request

## Guidelines

- Keep scripts minimal and focused on a single task
- Include a README in each script directory
- Add tests for new scripts (BATS preferred)
- Follow existing code style (`set -euo pipefail`, etc.)

## Branch Protection

- All changes must go through a Pull Request
- PRs require at least 1 approval
- CI tests must pass before merging

## Questions?

Open an issue if you have questions or suggestions.
